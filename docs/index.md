# astro-plugins

Personal Claude Code plugins that remove the frictions a solo developer runs into session after session. [PROJECT.md](https://github.com/astrosteveo/astro-plugins/blob/main/PROJECT.md) says what the project is for, and the [board](https://github.com/users/astrosteveo/projects/25) tracks its work.

- **Decisions:** why the project works the way it does, each too long for a line in PROJECT.md.
- **Notes:** what an experiment or an eval found, by date.
